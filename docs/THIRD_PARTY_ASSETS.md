# Third-party exercise artwork

The Movement Guide uses exercise artwork from
[`@bryllim/workout-guide`](https://github.com/bryllim/workout-guide) version 1.0.0.

- Original pose artwork: [Everkinetic](https://github.com/everkinetic/data)
- Expanded frames and normalized catalog: [Bryl Lim](https://bryllim.com)
- Artwork license: [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/)
- Package code and documentation: MIT

The application displays this credit on every exercise detail screen. Any
adapted artwork must retain attribution, indicate changes, and be distributed
under CC BY-SA 4.0.
