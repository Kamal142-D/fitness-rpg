# ADR 0003 — Follow the brief's palette over the anti-slop default

**Status:** Accepted

**Context.** `slop.md` warns against blue + blue-violet as a machine-made palette,
but `PLAN.txt` §7 specifies exactly that (electric blue `#3EA6FF`, accent
`#7B61FF`) as the product identity.

**Decision.** Follow the plan's palette — `slop.md`'s own rule is that a specific
user instruction overrides its defaults. Apply the anti-slop **craft** everywhere
else: tonal elevation and self-colored hairline edges (no default glow/heavy
shadow), no glowy pill buttons, bespoke tab/rune marks instead of an icon pack,
system-ui type rather than a trendy Google font, restrained accent usage, and
reduced-motion-safe animation with content visible by default.

**Consequences.** The app matches the brief's identity while avoiding the
execution tells. Revisit the palette during a dedicated visual-identity pass if
desired; a signature display face is a later decision.
